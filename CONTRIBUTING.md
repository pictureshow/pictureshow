# Contributing

Open an issue for feature requests and bug reports. Include the server version, device, and steps to reproduce a bug without credentials or personal data.

Code changes need tests that demonstrate the intended behavior. Run `./gradlew check assembleDebug` before proposing a change. Keep shared `commonMain` code platform-free and compatible with future Apple targets.

Contributions use MPL-2.0. Write original code or use dependencies with compatible licenses.
